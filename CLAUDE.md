## Data rules (the app's promise)
- The App Store build ships **no Google-derived data**. `ID_APP=1` switches `pipeline/idaho.py` into that mode and writes `data/app/places.json`
  (its calibration block keeps only Idaho license match rates and Colorado's Denver test). Copy it to `IdahoEats/Resources/places.json` after
  every rebuild; a unit test fails if rating/review/price/Google or inspection fields appear.
- **No inspections.** Idaho's seven public health districts publish inspections one search at a time (South Central's HedgehogPortal
  disallows Claude in robots.txt; Panhandle's legacy tool doesn't answer; Southwest has nothing online) and none issues a grade, placard
  or score. Never scrape them. The app and site say so and link each place's district lookup (`IdahoEats/Models/HealthDistrict.swift`,
  every URL fetched once and rendering on 2026-10-08). A bulk extract by records request (Idaho Code Title 74) needs Nick's yes.
- **Alcohol licenses.** Idaho State Police ABC's License/Permit Search and its Export are robots-disallowed (`Disallow: /AbcReporting/*/search`;
  Python's urllib.robotparser misses that wildcard, `pipeline/check_sources.py` has an RFC 9309 matcher). Nick exports Licenses.csv by
  hand in his browser into `data/raw/official/` (2026-10-08 decision); `pipeline/official.py` reads it, finds columns by name, and never
  shows the Licensee column. Renewal dates are staggered by county (Ada 4/30, Kootenai 2/28, Canyon 5/31, ...), not all 7/31.
- The themed guides (Basque, Finger Steaks & Drive-Ins, Spud Plates, Huckleberry, Idaho Trout, Taquerías, Historic Saloons) list only
  **hand-checked** places (`hc`), each with a 2025–26 source in `data/research/app/*.json`. James Beard honors (2023–26 + America's Classics)
  are in `data/research/jbf.json`; Idaho has no MICHELIN Guide. "Opened"/founded means at this address.
- Every cited or fetched host is robots-checked (idaho.py ignores a source whose host isn't checked or is blocked, and an entry left
  with no usable source isn't hand-checked): `cd pipeline && ../.venv/bin/python check_sources.py URL ...` (per URL) or with no
  arguments (every research record). data.bls.gov, Apple's search endpoints and the HedgehogPortal disallow Claude.
- Adult venues: `data/research/adult_venues.json` (Overture's adult_entertainment_venue category; The Torch Lounge in Boise is one, so the
  finger-steak origin story never lists it) plus name and Overture-category matching in idaho.py. Re-check against the ABC export.
- Hijacked pages (QA 2026-10-19, P1 #4; ported 2026-10-21): `check_websites.py` runs `pipeline/injection.py`, Wisconsin's detector, on every
  page (planted casino, betting, adult, pharma and link-farm links, visible, hidden or off-screen; other-language gambling text; parked
  and default pages). Keep it identical to `../wi-eats/pipeline/injection.py`; `test_injection.py` must pass. `--recheck-ok` fetches every
  passing page again before each submission (resumable: pages re-checked in the last 2 days are skipped), `--retry-transient` re-fetches
  429s and connection errors afterwards, and `CHECK_WORKERS=4` slows a run (Squarespace rate-limits across all our concurrent checkers).
- Tracking tags: the app export strips `ref=google`, `referrer=google_food_ordering`, `cn_channel`, `utm_*`, `fbclid`, Yext `cid=RF:YXT…`
  and similar from every outbound link (`pipeline/tracking_params.py`, the same in every state; store ids and locations stay). The site
  reads the app export, and a unit test fails if a tracked link is bundled (QA 2026-10-19, P1 #13).
- Website links: `pipeline/check_websites.py` (polite, honest UA, atomic saves, domains matched whole). Order: export, check, export.
  Re-run before each submission. 2026-10-08: 2,706 checked, 1,929 ok, 31 hijacked to gambling/adult pages.
- Website blocklist: `pipeline/website_blocklist.json` (hacked, expired, wrong-business or directory links found after the check; `match`
  "domain" or "url"). `scripts/make-site.py` drops those links from every page and from docs/data; qa-site.py fails if one is anywhere
  in docs/. The app's bundled places.json still has them until the next export (2026-10-12: goodyssodafountain.com hacked, missinglinkfoods.com
  expired, go-idaho.com a directory).
- Places the research finds closed go in `data/research/app/closed_*.json` with a source.

```bash
cd pipeline && ../.venv/bin/python listings.py && ../.venv/bin/python geocode_official.py && ../.venv/bin/python calibrate.py
../.venv/bin/python check_sources.py; ../.venv/bin/python idaho.py && ID_APP=1 ../.venv/bin/python idaho.py && ../.venv/bin/python geocode_census.py \
  && ID_APP=1 ../.venv/bin/python idaho.py && ../.venv/bin/python check_websites.py && ID_APP=1 ../.venv/bin/python idaho.py && cd ..
cp data/app/places.json IdahoEats/Resources/ && .venv/bin/python scripts/make-leaderboard.py && .venv/bin/python scripts/make-site.py && .venv/bin/python scripts/qa-site.py
```

(restaurants, hand-checked, honored, each guide) with the previous build: every tightened rule overreached once in Colorado.

## Build the app
- The Xcode project is **generated**: `xcodegen generate`. Never commit `IdahoEats.xcodeproj`.
- Compile without a simulator: `xcodebuild build-for-testing -project IdahoEats.xcodeproj -scheme IdahoEats -destination 'generic/platform=iOS Simulator' -derivedDataPath ./DerivedData CODE_SIGNING_ALLOWED=NO`
- Simulators: create our own ("ID Eats 6.9" = iPhone 17 Pro Max, "ID Eats iPad 13" = iPad Pro 13-inch) on iOS 27.0; one booted at a
  time; shut it down when done. Before booting check `ps -u $(id -u) | wc -l` (< ~2,300), `sysctl vm.swapusage` and that fewer than two
  other "… Eats" simulators are booted. Never touch other sessions' simulators.
- Unit tests: `test -only-testing:IdahoEatsTests` with `CODE_SIGNING_ALLOWED=NO`. UI smoke test: `-only-testing:IdahoEatsUITests` **without** it.
- Screens: `-screenshot <home|basque|fingersteaks|huckleberry|detail|map|honors|oldest|saved|about>` (DEBUG builds only; fixed location
  downtown Boise, 8th and Main). Saved places for the shots: `ScreenshotMode.savedNames` (a unit test checks they exist).
- **App Store builds come from the public Xcode**: `DEVELOPER_DIR="/Applications/Xcode 1.app/Contents/Developer"` (27.0); `Xcode.app` is a 27.1 beta.
  Check `DTXcodeBuild` in the archive; bump `CURRENT_PROJECT_VERSION` for every upload.
- `IdahoEats/Resources/PrivacyInfo.xcprivacy`: UserDefaults CA92.1, no tracking, no collected data.
- The "outside Idaho" message uses the state outline (`LocationService.outline`), not a box: Pullman and Jackson are inside Idaho's box.
