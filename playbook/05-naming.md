# Naming, icon and palette round (2026-10-08)

## Name
Candidates from the prompt's directions, checked 2026-10-08:
- **Idaho Eats** (chosen). No App Store app, guide or trademark found by web search (Apple's own search endpoints are robots-disallowed
  for automated agents, so the check went through ordinary web search). idaho**eats**.com is for sale at HugeDomains, which doesn't
  matter: the site is idaho.eatsranked.com. Matches the family ("Wisconsin Eats", "Colorado Eats", ...). "Idaho Eats" fits on the
  Home Screen in full, so no abbreviation.
- Gem State Eats: the nickname, but searchers type "Idaho"; gemstateeats.com is registered to an unrelated business; many "Gem State"
  businesses.
- Idaho Plates: a nod to the "Famous Potatoes" plate; web search returns license-plate pages, weaker for search.
- Avoided: the Idaho Potato Commission's "Grown in Idaho" seal and "Idaho" potato certification marks, "Idaho Preferred" (ISDA),
  Visit Idaho's taglines. "Spud" names read as potatoes only. A formal USPTO search is Nick's (not done by automation).

Nick's call: App Store "Idaho Eats: Restaurants", Home Screen "Idaho Eats", subtitle to be set from the guides (draft:
"Finger Steaks, Basque & Spuds").

jagged Sawtooth ridge. Nick picked **A**. `scripts/make-brand.swift` draws it for the app, the site and the og image.
2026-10-09: redrawn in the shared Eats Ranked icon style Nick approved (`../state-prompts/ICON-STYLE.md`): same potato, butter and hexes,
